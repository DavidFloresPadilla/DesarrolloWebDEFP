¿Qué es el Desarrollo Web?

Es el proceso de crear páginas y aplicaciones para internet combinando HTML para la estructura, CSS para el diseño y JavaScript para la interactividad.

Dato Curioso

CSS Grid permite crear diseños en dos dimensiones (filas y columnas) de forma muy sencilla.
